新しいものが上。不具合の報告は ギルドの固定スレッド 「🐞 フィードバックの送り方」（好きな言語で OK）か GitHub の Issue へ。

2026-09-19　クローズド β 公開

YouTube チャンネルメンバーとご支援者の方に向けて試験公開しました。Google でログインし、アンロックコード（メンバー限定動画の固定コメント、またはご支援のお礼メールに記載）を入力すると使えます。

できること

  • 図面・縫い穴・印刷（印刷キャリブレーション付き）。iPad（Apple Pencil）と Android タブレットでも動きます。
  • クラウド保存（版の履歴付き）。
  • 型紙の公開・共有（ライセンスを選んで公開）と「広場」での検索。
  • 掲示板「ギルド」（写真付き投稿、イイね、フォロー）。
  • デスクトップ版のデータ（.lcc）のインポート。

先にお断りしておくこと

  • デスクトップ版と完全に同じではありません。機能の有無や操作が異なる箇所があります。
  • デスクトップ版のデータはインポートできますが、曼荼羅機能など一部の機能はまだ対応していません。該当する図形は読み込めないか、見た目が変わることがあります。
  • デスクトップ版への書き出しにはまだ対応していません。
  • クラウド保存の容量は 1 人あたり 100 MB（図面は圧縮して保存、直近 2 版を保持）、写真は 1 人あたり 50 MB です。上限は今後見直すことがあります。
  • β 版です。予告なく変わることがあり、正式版として公開される保証はありません。

Release notes

Newest first. Report bugs in the pinned Guild thread "🐞 How to send feedback" (any language) or as GitHub issues.

2026-09-19　Closed beta

Opened to YouTube channel members and supporters. Sign in with Google and enter the unlock code (posted in the pinned comment of the members-only video, or sent in the thank-you mail to supporters).

What works

  • Drawing, stitching holes and printing (with print calibration). Runs on iPad (Apple Pencil) and Android tablets too.
  • Cloud save with version history.
  • Publishing patterns with a license of your choice, searchable in the Plaza.
  • The Guild board (posts with photos, likes, follows).
  • Import of desktop-version files (.lcc).

Please note

  • It is not identical to the desktop version. Some features and operations differ.
  • Desktop files can be imported, but some features such as the mandala mode are not supported yet. Affected shapes may not load or may look different.
  • Export to the desktop version is not available yet.
  • Cloud storage is limited to 100 MB per person (drawings are stored compressed, the latest 2 versions are kept) and photos to 50 MB per person. These limits may be reviewed.
  • This is a beta. Things may change without notice, and there is no guarantee that it will be launched as a final release.
